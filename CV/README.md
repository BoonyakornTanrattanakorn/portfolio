# Curriculum Vitae (RenderCV)

This directory contains the canonical RenderCV source and generated documents for the portfolio.

## Canonical Source

- `CV.yaml`: RenderCV YAML source defining experience, education, projects, skills, and contact details.

## Generation Command

RenderCV generation is decoupled from the web application build. To regenerate the document artifacts:

```bash
# Requires RenderCV (compatible with schema v2.6)
pip install "rendercv"

# On Windows PowerShell, ensure UTF-8 console output is enabled:
$env:PYTHONUTF8 = 1

# Run rendering from this directory:
rendercv render CV.yaml
# Or via python module:
python -m rendercv render CV.yaml
```

## Generated Outputs

- `Boonyakorn_Tanrattanakorn_CV.html`: Standalone HTML document with independent print styling.
- `Boonyakorn_Tanrattanakorn_CV.pdf`: Vector PDF version for direct download and viewing.
- `Boonyakorn_Tanrattanakorn_CV.typ`: Typst source generated by RenderCV.
- `Boonyakorn_Tanrattanakorn_CV.md`: Markdown export generated by RenderCV.

## Build Integration

The static portfolio build script (`scripts/build.js`) copies the committed HTML and PDF documents directly into `dist/CV/`. The build script validates that both `Boonyakorn_Tanrattanakorn_CV.html` and `Boonyakorn_Tanrattanakorn_CV.pdf` exist and fails the build clearly if either required document is missing.
