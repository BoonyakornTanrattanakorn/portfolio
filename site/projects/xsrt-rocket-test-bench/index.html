Overview

CUHAR (Chulalongkorn University High Altitude Rocketry) / XSRT is developing a static hot-fire test bench for a hybrid solid-liquid rocket engine. The system coordinates remote propellant filling, sensor acquisition, valve actuation, and ignition from an operator bunker 300 meters away.

As the Avionics and Embedded Systems Lead, my work focused on the test stand's electrical architecture, distributed 500 kbit/s CAN bus node infrastructure, and remote ground control integration.

Subsystems

  • Dual-Channel E-Match Ignition Module: Custom KiCad PCB with a 3 mF capacitive discharge bank (~5.9 A peak), active supply decoupling, and mechanical relay isolation for safe remote pyrotechnic ignition. (See full project writeup).
  • Servo-Actuated Ball Valves (SABV): CAN-connected actuator nodes controlling high-pressure valves with limit switch feedback and autonomous safe-state homing.
  • Stand Electronic Control Unit (ECU): Embedded controller managing sensor acquisition, communications, and safety interlocks.
  • Ground Control Station (GCS): Real-time telemetry monitoring and sequence control interface.
